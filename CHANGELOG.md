# Changelog

Each release of `@unset-sh/rendering` has an entry headed `## v<version>`, which the shared release workflow
uses as its release notes. Raise the version in `package.json` and add its entry in the same pull request.

## v0.1.0

- First release. Link preview images, 1200 x 630, for a profile, a post and an article, rendered from supplied
  data with colours, fonts and the mark from `@unset-sh/brand` 0.1.0.
